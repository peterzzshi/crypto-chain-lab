🔐 Encryption Algorithms Demo

Interactive visualisation of cryptographic algorithms with step-by-step calculations

RSA Public-Key Encryption

Enter a message and two prime numbers. Text input uses block encoding — each chunk of ⌊(n.bits()−1)/8⌋ bytes is encrypted as a separate RSA operation, supporting arbitrary-length input.

SHA-256 Cryptographic Hash

Enter any message to compute its SHA-256 hash. See the preprocessing, compression rounds, and final hash computation.

ECC Short Weierstrass — E(𝔽ₚ): y²≡x³+ax+b (mod p)

Arbitrary short Weierstrass curve over a prime field 𝔽ₚ (p ≤ 65521). Group order n is auto-computed by point enumeration (Euler's criterion, O(p·log p)). Defaults: E(𝔽₁₁) with G=(2,7), n=13.

secp256k1 — Bitcoin & Ethereum Key Derivation

SECG SEC 2 v2.0 curve: y² ≡ x³ + 7 (mod p). Used for ECDSA and Schnorr signatures in Bitcoin (BIP-340) and Ethereum (EIP-155). Enter a 256-bit private key as hex.
