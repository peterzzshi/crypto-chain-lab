🔐 Crypto Chain Lab

Interactive visualisation of cryptographic primitives and blockchain construction

RSA Public-Key Encryption

Enter a message and two prime numbers. Text input uses block encoding — each chunk of ⌊(n.bits()−1)/8⌋ bytes is encrypted as a separate RSA operation, supporting arbitrary-length input.

SHA-256 Cryptographic Hash

Enter any message to compute its SHA-256 hash. See the preprocessing, compression rounds, and final hash computation.

Keccak-256 — Ethereum's Native Hash

The original Keccak sponge construction (not NIST SHA3-256 — different padding). Used in Ethereum for address derivation, the EVM keccak256() opcode, EIP-712 typed-data signing, and Solidity's keccak256(). Rate = 1088 bits, capacity = 512 bits, 24 rounds of Keccak-f[1600].

ECC Short Weierstrass — E(𝔽ₚ): y²≡x³+ax+b (mod p)

Arbitrary short Weierstrass curve over a prime field 𝔽ₚ (p ≤ 65521). Group order n is auto-computed by point enumeration (Euler's criterion, O(p·log p)). Defaults: E(𝔽₁₁) with G=(2,7), n=13.

secp256k1 — Bitcoin & Ethereum Key Derivation

SECG SEC 2 v2.0 curve: y² ≡ x³ + 7 (mod p). Used for ECDSA and Schnorr signatures in Bitcoin (BIP-340) and Ethereum (EIP-155). Enter a 256-bit private key as hex.

ECDSA Message Signing

Sign a message with the private key above (RFC 6979 deterministic k). The resulting (r, s) signature can be verified by anyone with the matching public key.

ECDSA Signature Verification

Auto-populated after signing above. You can also paste any public key, signature (r, s), and message to verify any secp256k1 ECDSA signature.

Schnorr BIP-340 Message Signing

Sign a message with the private key above using BIP-340 Schnorr signatures (Bitcoin Taproot). Uses a tagged-hash nonce and produces an x-only (r, s) signature with an even-y nonce point. The signature equation s = k + e·d is linear, unlike ECDSA's k⁻¹(z + r·d).

Schnorr BIP-340 Signature Verification

Auto-populated after signing above. BIP-340 uses an x-only public key (32 bytes, no Y coordinate) — the verifier lifts X to the even-y curve point. Verify any secp256k1 Schnorr signature here.

BLS12-381 Message Signing

Sign a message with the private key above using BLS signatures (Boneh-Lynn-Shacham) over the BLS12-381 pairing curve. Public key is in G1 (48 bytes), signature in G2 (96 bytes).

BLS12-381 Signature Verification

Auto-populated after signing above. Verification checks the pairing e(pk, H(m)) = e(G1, sig). Verify any BLS12-381 signature here.

BLS12-381 Aggregate Signatures

Derives 3 keys from the seed above, signs the same message with each, aggregates the signatures into one, and verifies in a single pairing call e(∑pkᵢ, H(m)) = e(G1, agg_sig). Demonstrates BLS native non-interactive aggregation.

Shamir 2-of-3 Threshold Signing

Splits the private key into 3 shares using a degree-1 polynomial f(x) = d + a₁x mod n over the secp256k1 group order. Any 2 shares reconstruct d via Lagrange interpolation; 1 share reveals nothing. The demo reconstructs from shares 1 & 3, derives the public key, and signs a message with ECDSA to confirm the recovered key is correct.

AES-128 Block Cipher

Enter a 16-byte plaintext and 16-byte key as 32 hex characters each. Steps trace every round: key schedule expansion, AddRoundKey, SubBytes, ShiftRows, MixColumns, and final decryption verification.

⛓ Blockchain — Proof of Work
